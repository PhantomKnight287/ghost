## Trying it by hand

1. Register an app under **Settings → OAuth apps**, and copy its client ID here.
2. Open the URL in a browser where you are signed in to Ghost, and approve the app.
3. Ghost redirects to your callback. If nothing listens there yet, copy the `code` from the address bar of the page that fails to load.
4. Within 10 minutes, run the `curl` command with that code and your client secret in `GHOST_CLIENT_SECRET`. A code works once, and a failed exchange uses it up.

See [Authorizing users](/oauth-apps/authorizing-users) and [Exchanging the code](/oauth-apps/exchanging-the-code) for what each parameter means.

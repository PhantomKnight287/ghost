Ghost is a self-hosted git hosting platform. Push and pull over HTTP or SSH,
browse trees and blobs, open pull requests across branches and forks, and track
work in issues.

## Connecting over SSH

HTTP asks for a personal access token every time something forgets it. SSH
asks for a key once, and then stays out of the way.

## Signing your commits

A commit records whoever the `user.email` setting says wrote it. Nothing stops
anyone from setting that to your address. Signing a commit with a GPG key you
control is what turns "this commit claims to be from you" into "this commit
was made by whoever holds your key".
